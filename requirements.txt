# ── torch (GPU 가속) ─────────────────────────────────────────────
# torch/torchvision 은 ultralytics 가 알아서 끌고 오는데, 그 기본값이 CPU 전용
# 빌드(`2.14.0+cpu`)다. 이걸 그대로 두면 NVIDIA GPU가 꽂혀 있어도 전부 CPU로 돌아
# 프레임당 약 360ms(1080p, 두 모델 합) 가 걸린다. GPU로는 20ms 내외다.
#
# 여기에 버전을 고정하지는 않는다 — GPU 없는 팀원의 설치가 깨지면 안 되기 때문이다.
# NVIDIA GPU가 있다면 설치 후 아래를 한 번 더 실행하세요 (약 2.5GB, 몇 분 걸림):
#
#   pip install --force-reinstall torch torchvision --index-url https://download.pytorch.org/whl/cu130
#
#   * cu130 = CUDA 13.x 드라이버용. 드라이버가 12.x 대면 cu128 을 쓰세요
#     (`nvidia-smi` 우측 상단의 CUDA 버전으로 확인).
#
# 확인: python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#       → `2.14.0+cu130 True` 가 나와야 합니다. 앱 사이드바에도 GPU/CPU 가 표시됩니다.
# 강제로 CPU를 쓰고 싶으면 .env 에 INFER_DEVICE=cpu 를 넣으세요.
