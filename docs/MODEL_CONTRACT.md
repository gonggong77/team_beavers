# 모델 인계 요청서

수신: 이규남, 정해찬 · 발신: 이현경(웹) · 대상: `core/detector.py` 의 `YoloDetector`

웹 쪽은 모델 없이도 화면이 전부 돌아가는 상태입니다. 아래 두 가지만 주시면 바로 붙습니다.

## 1. 지금 바로 필요한 것

```
pip freeze | grep -i ultralytics
```

이 한 줄의 출력값을 공유해 주세요. 서로 버전이 다르면 `.pt` 로딩 단계에서 깨집니다.
받는 즉시 `requirements.txt` 에 정확히 핀 고정하겠습니다.

## 2. D5까지 필요한 것

**1에폭만 돌린 더미 `best.pt`** 를 먼저 주세요. 성능은 0이어도 상관없습니다.
형식만 맞는 파일이 있으면 통합 리스크가 사실상 사라집니다.
성능이 나오는 최종 가중치는 나중에 같은 경로에 덮어쓰기만 하면 됩니다.

## 3. 웹 쪽이 이미 자동으로 처리하는 것 (알려주지 않아도 됩니다)

| 항목 | 처리 방식 |
| --- | --- |
| 클래스 인덱스와 이름 | `model.names` 를 런타임에 읽습니다. 이름으로 자동 추정하고, 실패하면 사이드바에서 사람이 직접 매핑합니다. 클래스를 3개 이상으로 늘려도 대응됩니다 |
| `imgsz` | `model.ckpt["train_args"]["imgsz"]` 에서 읽고, 없으면 640을 씁니다 |
| `conf` / `iou` | 사이드바 슬라이더로 조절합니다. 기본값 0.25 / 0.7 |
| 좌표계 | `boxes.xyxy` 와 `masks.xy` 만 사용합니다. 둘 다 원본 프레임 픽셀 좌표로 나오므로 별도 변환이 필요 없습니다 |

## 4. 지켜주셔야 하는 전제

- **모델은 두 개로 나뉘었습니다** (2026-09-17 반영). 이안류 탐지 모델과, CCTV 원거리 시점에서
  표류 중인 사람을 찾는 사람 탐지 모델을 따로 주세요. 웹 쪽 `DualDetector` 가 두 결과를 합쳐
  "사람이 이안류 구역 안에 있는가"를 판정합니다. 한쪽만 먼저 주셔도 됩니다.
- **이안류는 `segment` 를 권장**합니다. 구역을 폴리곤으로 받아야 포함 관계가 정확합니다.
  `detect` 도 동작은 합니다(박스를 사각형 폴리곤으로 대신 씀). 다만 사각형이 실제 이안류보다
  넓어서 구역 안/밖 판정이 후해집니다.
- 클래스 이름은 가능하면 `rip_current`, `person` 처럼 영문으로 주세요. 자동 매핑이 바로 맞습니다.
  이름이 힌트에 안 걸리면 그 모델의 **전체 클래스**를 해당 용도로 취급하므로,
  한 모델 안에 목적과 무관한 클래스를 섞지 말아 주세요.

## 5. 인계 방법

1. 이안류 모델은 `models/rip/`, 사람 모델은 `models/person/` 에 넣습니다.
   (또는 `.env` 의 `RIP_MODEL_PATH` / `PERSON_MODEL_PATH` 에 경로를 직접 지정)
2. 앱을 새로고침하면 사이드바 모델 표시가 `이안류 실제 추론 / 사람 실제 추론` 으로 바뀝니다.
3. 두 모델을 `models/` 바로 아래에 같이 두지 마세요. 어느 쪽이 이안류인지 이름순으로 정해져
   섞일 수 있습니다.
